================================================================================
double slash is not a comment
:error
================================================================================

x = 1; // not a comment

--------------------------------------------------------------------------------

================================================================================
splice is only valid inside argument lists
:error
================================================================================

x = @y;

--------------------------------------------------------------------------------

================================================================================
index form of for cannot use a range
:error
================================================================================

for v, i in [1..2]
endfor

--------------------------------------------------------------------------------

================================================================================
computed dollar verb names are not MOO
:error
================================================================================

$(name)();

--------------------------------------------------------------------------------

================================================================================
a binary expression is not an assignment target
:error
================================================================================

x + 1 = 2;

--------------------------------------------------------------------------------

================================================================================
a literal is not an assignment target
:error
================================================================================

2 = {};
